# Source code

This directory contains the frontend and data-integration code for PulseCast.

```text
src/
├── components/   # Reusable dashboard UI
├── views/        # Page-level screens
├── data/         # Replay fixtures and data adapters
├── services/     # API, model, and streaming clients
├── charts/       # Risk and sensor visualizations
├── styles/       # Shared theme and layout styles
└── types/        # Shared data contracts
```
